# First Light equipment needs — procurement held until funded

This is a requirements-driven outline, **not a shopping cart** or a claim that inventory is on hand. Exact part numbers and prices are not selected or quoted.

| Category | Why needed | Acceptance check |
| --- | --- | --- |
| Two or more compatible OpenThread development endpoints | Real 802.15.4 test exchange | Versioned OpenThread firmware and reproducible receipt path |
| Two direct LoRa-capable endpoints | Independent physical transport experiment | Confirm local band/regional limits, duty/airtime constraints and approved RF setup |
| LEDs, haptic actuators and controllers | Testable perceivable signaling | Safe current limits, explicit test-only actuation, independent sensor reference |
| Photodiode / accelerometer / logic analyzer / scope | Independent evidence that something actually lit or vibrated | Calibrated sampling, synchronized timestamps and error estimates |
| Controlled power/network fault setup | Repeatable failure and brownout exercise | Bounded stop controls, fuses/isolations, structured failed-trial logging |
| Accessible test interface and lab support | Reproduce stimuli and compare visual/haptic/text paths | Human testing only after relevant consent/review |

Acquire no hardware until approved budget, vendor quotes, bench safety, lawful RF plan and responsible operators are documented. The current software version remains safe to explore without physical equipment.
